# PowerPoint UI reference

This document is the UI contract for Slide Aid. The PowerPoint add-in is the main product; companion implementations should copy its names, order, icons, defaults, and behavior unless their platform makes that impossible.

The machine-readable source of truth is [`ribbon/customUI14.xml`](../ribbon/customUI14.xml). Icons are PNG files in [`ribbon/images/`](../ribbon/images/), generated by [`tools/make_icons.py`](../tools/make_icons.py). Functional behavior lives in [`src/`](../src/). If this document and the ribbon differ, follow the ribbon and update this document.

## Shared conventions

- **Master:** the object selected last. With one selected object, Master-based position commands use the slide instead.
- **Units:** user-entered distances are centimetres; PowerPoint geometry is converted internally to points.
- **Selection-order commands:** Swap, Stack, Matrix, Merge Text, and similar commands use click order.
- **Chart datasheet:** a selected PowerPoint table. The top-left cell is normally blank, categories run across row 1, series names run down column 1, and numeric values occupy the body. Exceptions are described in [`CHARTS.md`](CHARTS.md).
- **Chart identity:** generated elements carry `SACH_*` tags so data, chart type, style overrides, and edit/rebuild state survive later changes.

### Position behavior

| Control | Ribbon tag(s) | Behavior |
|---|---|---|
| Left / Right / Top / Bottom / Center / Middle | `AlignM:L/R/T/B/CH/CV` | Align selected objects to the corresponding Master edge or centre line. A single object aligns to the slide. |
| To Slide | `AlignS:L/R/T/B/CH/CV` | Same align operations with the slide forced as the reference. |
| Distribute H / V | `Distrib:H/V` | Make gaps equal while the outermost objects keep their positions. |
| Swap | `Swap:*` | Rotate positions in selection order. The submenu chooses centre/corner anchoring, whether sizes move too, and whether the layer order is swapped. |
| Dock | `Dock:L/R/T/B` | Move objects until they touch the corresponding side of the Master; a single object uses the slide. |
| Stack | `Stack:H/V`, `StackGap:H/V` | Arrange in selection order, touching or using a remembered fixed gap. Negative gaps overlap. |
| Matrix / Matrix… | `Matrix:Q/O` | Arrange row by row in a near-square grid, or prompt for columns and horizontal/vertical gaps. |
| Place on Slide | `Place:LH/RH/TH/BH/L3/C3/R3/Q1/Q2/Q3/Q4/FULL` | One object fills the chosen region with a small margin; several objects move as a block. |
| Spacing | `Spacing:H/V` | Set an exact remembered gap in current positional order. |
| Golden Canon | `Golden:0` | Position targets vertically inside the Master so the bottom margin is twice the top margin. |

### Size, shape, color, and text behavior

| Control | Ribbon tag(s) | Behavior |
|---|---|---|
| Magic Resizer | `Magic:0` | Scale width, height, and font sizes about each object centre by a percentage. |
| Width / Height / Width + Height | `Size:W/H/WH` | Match the Master's dimensions while retaining object centres. |
| Stretch | `Stretch:L/R/T/B` | Extend the chosen edge to the corresponding Master edge; the opposite edge stays fixed. |
| Fill Gap | `FillGap:L/R/T/B` | Extend each object towards the Master until the gap closes. |
| Slice / Multiply | `Slice:0`, `Multiply:0` | Split one object into a rows-by-columns grid inside the original footprint, or create a grid of full-size duplicates. |
| Process Chain | `ProcChain:0` | Match the Master's arrow angle, vertical position, and height, then close horizontal gaps. |
| Align Angles | `Angles:0` | Copy Master rotation and, for compatible shapes, adjustment handles. |
| Block Arrows / Rounded Rect. | `BlockArr:0`, `RoundRect:0` | Normalize arrow metrics or absolute corner radii to the Master. |
| Snap to Table | `TblSnap:C/L/R` | Place objects in the table cell under them, centred or aligned with a chosen margin. |
| Fill / Line / Font | `ThemeCol:*`, `PalCol:*` | Apply slide-theme-linked colors or fixed RGB palette colors. Theme swatches use `sa_sw_t*.png`; palette swatches use `sa_sw_p*.png`. |
| Convert to RGB / Convert to Theme | `Theme2RGB:0`, `RGB2Theme:0` | Convert theme colors to fixed RGB or map matching RGB colors back to theme-linked colors. |
| Pick from Master / Color Info | `PickCol:*`, `ColInfo:0` | Copy a Master color to targets or report RGB and hex values. |
| Split / Merge Text | `TxtSplit:0`, `TxtMerge:0` | Split at the cursor or merge text in selection order. |
| Margins / Fit / Wrap | `TxtMargin:0`, `TxtFit:0`, `TxtWrap:0` | Set text margins, fit form to text, or toggle wrapping. |
| Text Tools | `TxtCase:U/L/T/S`, `TxtTidy:0`, `TxtSwap:0` | Change case without losing formatting, remove double spaces, or swap text between two objects. |

The nine Chart Aid palettes, in gallery order, are **Office**, **Nordic Blue**, **Fjord**, **Forest**, **Sunset**, **Berry**, **Greyscale**, **Financial**, and **Vivid**. A palette change is global; Restyle rebuilds charts without losing stored data or per-series overrides.

Chart layouts and chart-specific semantics are maintained in [`CHARTS.md`](CHARTS.md). In particular, Waterfall supports `e`/`=` subtotal rows, Scatter uses `label | x | y`, Bubble adds a size column, and Gantt uses `activity | start | end` with equal start/end values rendered as milestones.
